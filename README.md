# Sunset Ninja Run

A 2D endless runner built with HTML, CSS and JavaScript (Canvas).

## Features
- Double jump and slide mechanics
- Fire and bat obstacles
- Power-ups: shield and magnet
- Coins, levels and best score (saved in localStorage)
- Parallax backgrounds with changing palettes
- Sound effects and music generated with the Web Audio API (no audio files)

## Controls
- Jump: Space / W / Up arrow / tap
- Slide: S / Down arrow / tap the lower part of the screen
- Pause: P, Mute: M

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.
